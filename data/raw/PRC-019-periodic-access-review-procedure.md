# Periodic Access Review Procedure

**Process owner:** Priya Nair (Security Governance)
**Governing policy:** POL-014

## 1. Frequency
- Data owners review all user access to the systems they own **quarterly** (CTL-07).
- Contractor access to systems holding Restricted data is reviewed **monthly**. This was added in v1.1 following INC-2026-031.

## 2. Method
Gatekeeper IAM generates the review list. Data owners confirm or revoke each entitlement.

## 3. Unreviewed access
Access that has not been reviewed within **10 business days** of the review starting is revoked automatically.
